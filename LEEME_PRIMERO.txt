AUDITOR IA - TRANSCRIPTOR 8.0.0
ESTABLE · PROCESAMIENTO NO BLOQUEANTE
================================================

PROBLEMA CORREGIDO
------------------
Las versiones anteriores ejecutaban la IA pesada dentro del mismo proceso
que mostraba la ventana. Aunque se utilizara QThread, PyTorch, pyannote y
Faster-Whisper podían consumir suficiente CPU para que Windows mostrara
"No responde".

ARQUITECTURA 8.0.0
------------------
INTERFAZ WINDOWS
      |
      | inicia un proceso independiente
      v
PROCESO IA
  - prepara audio
  - Faster-Whisper Small
  - Community-1
  - ECAPA Rescue cuando corresponde
  - asigna AGENTE / CLIENTE
      |
      | devuelve progreso + resultado
      v
INTERFAZ WINDOWS

Al seleccionar un archivo la interfaz NO abre el audio, NO lee metadatos y
NO carga modelos. El trabajo pesado comienza solo al presionar TRANSCRIBIR.

Además:
- la IA corre con prioridad inferior a la interfaz;
- se reservan núcleos para Windows;
- existe botón CANCELAR;
- el progreso se comunica sin bloquear la ventana.

SE CONSERVA
-----------
- Transcripción de archivos.
- Transcripción en vivo.
- Faster-Whisper Small.
- Community-1.
- ECAPA Rescue.
- Speaker V2.
- Historial.
- Ajustes.
- TXT / Word.
- Corrección manual AGENTE / CLIENTE.
- Sin API.
- Sin pagos.
- Solo instalador Windows.
- Sin Portable.
