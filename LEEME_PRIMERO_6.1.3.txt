CARPETA COMPLETA PARA GITHUB

Esta carpeta ya contiene el proyecto completo. NO necesitas una carpeta anterior ni pegar un parche sobre otra versión.

INCLUYE
- Proyecto completo del Transcriptor.

SPEAKER V2
- Timestamps por palabra para archivos.
- exclusive_speaker_diarization de Community-1.
- Alineación palabra por palabra con la voz detectada.
- Divide un segmento de Whisper si contiene a ambos participantes.
- Determina AGENTE/CLIENTE por la estructura global de la conversación.
- NO supone que la primera persona en hablar sea el agente.
- El selector histórico de primer hablante queda solo como fallback si el análisis es ambiguo.

PARA USARLA
1. Descomprime esta carpeta.
2. Si tu repositorio local está vacío, copia TODO su contenido dentro.
3. Ejecuta:
   git add .
   git commit -m "AUDITOR IA 6.1.3 Speaker V2"
   git push origin main
4. GitHub > Actions > Build Windows release > Run workflow > main.

El workflow descarga los modelos durante el build usando el secreto HF_TOKEN que ya configuraste en GitHub.
