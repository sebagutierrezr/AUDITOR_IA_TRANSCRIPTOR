AUDITOR IA - TRANSCRIPTOR 8.0.1 STABLE
=====================================

ESTE PAQUETE ES UNA VERSION COHERENTE COMPLETA. NO MEZCLAR ARCHIVOS 8.0.0 CON 8.0.1.

OPCION RECOMENDADA
------------------
1. Descomprime este paquete sobre la carpeta raiz de tu repositorio.
2. Acepta reemplazar todos los archivos existentes.
3. No reemplaces ni borres la carpeta oculta .git.
4. Ejecuta en PowerShell desde la raiz del proyecto:

   git add -A
   git commit -m "AUDITOR IA 8.0.1 estable transcripcion y en vivo"
   git push origin main

5. En GitHub ve a Actions -> Build Windows Installer 8.0.1 STABLE -> Run workflow.
6. Descarga el artifact AUDITOR_IA_8.0.1_Setup.
7. Ejecuta AUDITOR_IA_8.0.1_Setup.exe. Conserva el mismo AppId de 8.0.0, por lo que actualiza la instalacion anterior.

CAMBIOS CRITICOS
----------------
- Archivo: el worker ya NO usa stdout para comunicarse con la interfaz.
- Archivo: el proceso pesado corre separado, con prioridad reducida y watchdog.
- Archivo: Faster-Whisper Small transcribe; SortFormer solo diariza.
- Archivo: un fallo/timeout de SortFormer no elimina el texto transcrito.
- SortFormer: no usa PIPE stdout/stderr sin drenar; se evita deadlock.
- SortFormer: full-attention solo en llamadas cortas; streaming en llamadas largas.
- En vivo: grabaciones en LOCALAPPDATA, no Program Files.
- En vivo: audio cliente por WASAPI loopback con PyAudioWPatch.
- En vivo: captura y transcripcion en hilos separados; beam 1 para baja latencia.
- Build: NeMo-Speech CPU oficial v0.1.0 precompilado, sin compilar C++ desde cero.
- Build: el conversor de SortFormer usa un venv aislado y no cambia las dependencias de la app.
- Build: prueba el EXE empaquetado y el modo --file-worker antes de generar el Setup.
